# 宠物王国：灵契

《宠物王国》世界观的非商业同人续作可玩序章。

在线试玩：[GitHub Pages](https://weiwei-cup.github.io/pet-kingdom-spirit-pact/)

彩虹庆典上，所有登记过灵契的宠物同时忘记主人。玩家将从临虹村出发，选择第一位主动跟随自己的伙伴，完成捕捉与学院考核，并在灵契断裂事件中守护白裂狮的三段记忆。

## 序章内容

- 三种初始伙伴与独立属性、技能
- 键盘、鼠标及触屏野外移动
- 安抚与捕捉教学
- 可重复的高草遭遇、野生反击、胜败与撤离
- 等级、攻防与十种属性克制参与伤害计算
- 四技能槽与持续保存的金币、胶囊、莓果
- 青崖调查营地、旅行商店与生态调查支线
- 青崖水道和彩虹城南门双向通行
- 彩虹学院回合制考核
- 万灵共鸣仪式与历代主角登场
- 以保护记忆为核心的唤灵首领战
- 浏览器本地自动存档

## 本地运行

需要 Node.js 22.13 或更高版本。

```bash
npm install
npm run dev
```

## GitHub Pages

推送到 `main` 分支后，GitHub Actions 会自动生成并发布静态版本。
